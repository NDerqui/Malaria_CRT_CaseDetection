# A workflow for modelling the design of (cluster-) randomised clinical trials for malaria interventions

Code for running trial simulations, cleaning and analysing their outcomes, and estimating effect size and trial power.
Simulations are run using Imperial College London's [malariasimulation](https://github.com/mrc-ide/malariasimulation) model, for which there is much more and far better documentation available [here](https://mrc-ide.github.io/malariasimulation/index.html).
The code available in the repository presents a workflow using the model above, with helper functions to run simulations and analyse their outcomes in the context of simulation clinical trials.
